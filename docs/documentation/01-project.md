# 폴더와 시스템 구조

| Scripts/Management | 게임 모드·씬 전환·공통 프리팹 초기화 |

| Scripts/Utils | 풀, 싱글톤, 캐시 |

| Scenes | Playground·직접 Play 가능한 씬 전환 예제 |
| Input | 입력 액션 |
| AddressablesResources/Prefabs | 자체 캐릭터·HUD·UI 프리팹 |
